# MGN902: Export Import Procedure and Documentation
## Master Coursework, Revision & Exam Preparation Repository (Units I, II & III)

Welcome to the definitive, student-centric academic repository for **MGN902: Export Import Procedure and Documentation**. 

This repository is engineered to take a student with **zero prior knowledge** of foreign trade and guide them through three stages:
1. **Understand intuitively** via plain-language Concept Notes, real-world Indian exporter narratives, and intuitive flowcharts.
2. **Practise comprehensively** via rigorous Objective Question Banks (MCQs, T/F, Fill-in-the-blanks, Match, Assertion-Reason, Scenario problems) and standard University-pattern Subjective Model Answers.
3. **Revise rapidly** in the final hours before the examination using 2-page Quick Revision sheets, content-tied Mnemonics, Top Exam Traps, and Cross-Unit Comparison Tables.

## 4. Academic Rigor & Pedagogical Principles

1. **Zero Jargon Without Plain Explanation:** Every concept begins with *"In one minute"* and a relatable Indian exporter story (e.g., Tirupur knitwear, Surat diamonds, Nashik grapes).
2. **Exhaustive Rationale in Objective Banks:** For every MCQ, the answer states why the correct option is correct *and* why each incorrect option is wrong, linking back to the concept notes.
3. **Dual-Layer Subjective Answers:** For complex legal concepts, answers provide both the formal statutory structure required for full marks from strict evaluators and a concise *"Student-Friendly Version"* that can be drawn and written in 15–20 minutes.
4. **Current Policy vs Historical Syllabus Nuance:** Where syllabi mention historical procedures (e.g., Central Excise rebate, ARE-1, CT-1, physical GR forms), both the traditional answer and the modern post-GST / ICEGATE position are provided, advising the student exactly how to answer based on the examiner's phrasing.
